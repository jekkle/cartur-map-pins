## Medium - confirmed by lead (*) or by two reviewers independently (2x)
1. * PinSharing=Nothing strips OTHER players' pins from the cartography table, and AddSharedMapData
   then deletes them for every reader. Patches.cs:26-50. Fix: never withhold m_ownerID != 0.
2. * LocalizeNames rewrites hand pins containing '$' ("Stash $5" -> "Stash [5]", Localization.cs:468).
   PinRecord.cs:377-406. Fix: only rewrite when every token resolves (no "[...]" produced).
3. * Pin editor Confirm rewrites vanilla token names ("$location_x" -> " location_x") even when only
   colour/icon changed; box shows the raw token. PinEditor.cs:64-65, 515-523. Fix: show and compare
   against the localized name; write only when the text was changed.
4. * Zoom shrink / crowding / hover act on area pins (raid circle, m_worldSize > 0): the event circle is
   drawn at 60% of its real radius. No m_worldSize check anywhere in src. PinFade.ScaleFor,
   Crowding.cs:188-197, PinHover.Find. Fix: skip m_worldSize > 0.
5. 2x Death-pin cleanup keyed on ZDO network owner, not the dead player. Patches.cs:654-657 /
   PinPlacer.cs:150. Fix: require tombstone ZDOVars.s_owner == local player ID.
6. 2x Dedicated server: AddInstance queue + ChestRegistry grow forever (no local player to drain).
   Fix: [BepInProcess("valheim.exe")] or no-op when dedicated.
7. Friends' shared pins (m_ownerID != 0) adopted as ours by ExistsOnMap / FindPinAt / RepairPositions /
   SweepLootedChests. Fix: skip m_ownerID != 0.
8. Dungeon sweep unticks pins the player ticked by hand (every 2 s while loot left). PinPlacer.cs:314-349.
9. Hidden labels pop back ~1 s after creation (vanilla DelayActivation coroutine). LabelCrowding.
   Fix: one extra pin update ~1.1 s after labels are built.
10. Merge key (cell, name) ignores type: two unnamed hand pins of different icons collapse. Crowding.cs:241.
11. Editor stays open across map close, can write a style for a deleted pin. PinEditor.cs:78-84.
12. Search active + HideCollidingLabels=false still hides colliding labels. LabelCrowding.cs:68-111.
13. BELIEVED: Esc in the search box also closes the map (TextFocus uses live isFocused). Needs a test.
